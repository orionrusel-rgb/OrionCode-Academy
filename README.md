# OrionCode Academy — IT & Coding Academy

Responsive bootcamp landing page for OrionCode Academy — *Master Full-Stack & AI Bootcamp*. Built with HTML, CSS, and JavaScript in a single file.

**Live demo:** https://orionrusel-rgb.github.io/OrionCode-Academy/

## Features

- Filterable bootcamp catalog (Tech Track / Level / Duration)
- Pricing tiers, graduate showcase, advisor form & newsletter
- Scroll animations, count-up stats, glass navbar, mobile scroll-snap rails
- Fully responsive, from 320px phones to desktop

## Tech

HTML · CSS · JavaScript — single-file build, no framework.

## Structure

- `index.html` — the complete site (markup, styles, scripts, and inlined images)
